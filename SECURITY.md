# Security Policy

## Supported versions

This project is in early development (pre-1.0). Only the latest commit on the `main` branch receives security fixes. There are no release channels yet.

## Reporting a vulnerability

Please do **not** open a public issue or pull request for security vulnerabilities. Instead, report them privately to the maintainer through GitHub's **private vulnerability reporting** feature:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Provide a clear description, the affected area, and steps to reproduce (if any).

Alternatively, you can contact the maintainer privately through their GitHub profile.

## What to include

- The affected component/file and version (commit hash if known).
- A description of the vulnerability and its potential impact.
- Proof of concept or reproduction steps, when possible.

## What happens next

The maintainer will acknowledge your report, investigate it, and work on a fix. You will be credited for the discovery if you wish to be named. Please allow reasonable time for a response — this is a solo-maintainer project.

We ask that you do not disclose the vulnerability publicly until a fix has been published and communicated.
